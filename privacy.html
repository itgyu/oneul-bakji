개인정보처리방침

I will be back (아윌비백) · 시행일 2026년 11월 4일 · 이름 변경, iPhone·iPad 앱, 기기 이어하기, 운영자의 이용 제한 추가 2026년 11월 6일

요약

  • 회원가입, 로그인, 이메일 없이 이용해요. 캠퍼 진행은 기기와 서버에 함께 저장해서, 휴대폰·태블릿·웹 어디서든 같은 캠퍼로 이어 할 수 있어요(3번). 서버에는 무작위 번호로만 묶어 두고, 누구인지 알 수 있는 정보는 받지 않아요.
  • 게임을 다듬으려고 익명 이용 통계(어떤 박지·장비를 고르고 얼마나 머무는지)를 모아요. 기기에 고유 번호를 붙이지 않아서 누구의 기록인지 알 수 없어요.
  • 음성, 채팅 내용, 캠퍼 이름, 정확한 위치, IP 주소는 모으지 않아요.
  • 설정 → 익명 이용 통계 → '안 보내기'로 언제든 끌 수 있어요. 꺼도 게임은 똑같이 할 수 있어요.
  • 외부에 공개하거나 제공하는 건 개인을 알아볼 수 없는 집계 숫자뿐이에요.
  • iPhone·iPad 앱은 이용 통계를 보내지 않아요(8번).

1. 개인정보 처리

I will be back(아윌비백)은 회원가입 없이 이용해요. 이름, 연락처, 계정 같은 개인정보를 수집하지 않아요. 아래 2번의 이용 통계와 3번의 서버 저장은 특정 개인을 알아볼 수 없도록 설계했어요.

2. 익명 이용 통계

목적게임 개선(많이 찾는 박지와 기능, 성능, 이용 흐름 파악)과, 장비·의류 선택 경향처럼 개인을 알아볼 수 없는 집계 통계 작성
보내는 것 게임 안 행동(박지 입장과 머문 시간, 고르거나 시험해 본 옷·장비와 그 시간, 텐트 치기·커피·모닥불 같은 활동, 받은 도장, 레벨이 오른 때와 끝낸 의뢰, 1박한 밤의 날씨 난이도와 잘 잤는지, 새로 열린 장비와 칭호, 주간 목표와 계절 도장을 채운 때, 잠긴 장비를 입어 봤는지, '실제 제품 찾아보기' 클릭, 다른 캠퍼의 장비가 화면에 보인 시간과 인원 수, 채팅·표정을 쓴 횟수, 음성을 쓴 시간) · 기기 정보(기기 종류, 대략적인 화면 크기, 언어, 시간대, 화질 설정, 평균 프레임) · 유입 경로(직전 사이트의 도메인, 캠페인 태그) · 방문 표시(오늘·이번 달 첫 방문인지, 처음 온 날부터 며칠째인지, 모두 며칠 왔는지)
보내지 않는 것음성 내용, 채팅 내용, 캠퍼 이름, 정확한 위치, 연락처, IP 주소(분석 서비스가 저장하지 않게 설정하고, 위치 추정도 끄고 보내요), 기기를 알아볼 수 있는 고유 번호
묶는 방식방문할 때마다 새로 만드는 무작위 번호로 그 방문 안의 기록만 묶어요. 이 번호는 저장하지 않아서 다른 날의 방문과 이어지지 않아요.
기기에 남기는 것통계를 껐는지, 처음과 마지막으로 온 날짜, 온 날 수, 이번 달에 이미 알린 장비 목록이에요. 사람 수를 번호 없이 세는 데만 쓰고 기기 안에만 있어요. 통계를 끄면 지워요.
저장·분석 서비스PostHog, Inc. (미국 데이터 센터, 암호화된 연결(https)로 전송)
보관 기간원본은 13개월이 지나면 지워요. 집계 통계(예: 분기별 장비 선택 비율)는 계속 보관할 수 있어요.
외부 제공개인을 알아볼 수 없도록 묶은 집계 통계는 공개하거나 외부에 제공할 수 있고, 이때 50명 미만이 해당하는 항목은 넣지 않아요. 방문 단위 원본은 제공하지 않아요.
끄는 방법설정 → 익명 이용 통계 → '안 보내기'. 브라우저가 추적 거부(GPC) 신호를 보내면 보내지 않아요. 유럽 시간대 기기에서는 처음부터 꺼져 있고, 설정에서 켤 때만 보내요.

3. 기기 이어하기 (서버 저장)

목적같은 캠퍼를 휴대폰, 태블릿, 웹, 앱 어디서든 이어 하고, 기기를 바꾸거나 저장소가 지워져도 진행을 지키며, 하루에 늘 수 없을 만큼 부풀린 기록을 막기 위해
처리 항목캠퍼 진행(캠퍼 이름·모습·장비·도장·기록·레벨·야영 일지, 무작위 캠퍼 번호), 저장 시각, 기기 열쇠의 해시(SHA-256. 열쇠 자체는 기기에만 있어요), 기기 연결 코드의 해시(10분 뒤 지워요)
받지 않는 것실명, 이메일, 전화번호, 로그인 계정, 위치, 기기 고유 번호. 운영자는 서버 접속 기록(IP 주소)을 따로 모으지 않아요.
보유 기간지울 때까지예요. 설정 → 기기 이어하기 → '서버 기록 지우기'를 누르면 모든 기기의 서버 기록을 바로 지워요. '이 기기 연결 끊기'는 그 기기만 빼요. 각 기기의 사본은 그대로 남아요.
처리 위탁Supabase, Inc. — 데이터베이스
이용자의 권리언제든 지울 수 있어요. 저장된 내용을 보거나 고치려면 아래 문의로 알려 주세요.

예전에 안내한 '계정으로 저장(구글·카카오 로그인)'은 쓰지 않아요.

4. 서비스 제공 과정의 접속 기록

서비스를 제공하는 과정에서 아래 곳들이 접속 기록(IP 주소 등)을 처리할 수 있어요. 운영자는 이 기록을 따로 모으지 않아요.

  • 사이트 호스팅: GitHub Pages(GitHub, Inc.)
  • 글꼴 전송: Google Fonts
  • 서버 저장(3번)과 운영자의 이용 제한 기록(6번): Supabase, Inc.
  • 함께하기 연결: 무료 신호 서버 PeerJS(0.peerjs.com). 연결된 뒤에는 브라우저끼리 직접 통신해요(P2P).
  • 실시간 날씨: Open-Meteo

5. 함께하기에서 전해지는 정보

같은 박지에 있는 다른 이용자에게는 캠퍼 이름과 모습, 레벨과 칭호, 배낭 패치(받은 도장의 박지 색), 무작위 캠퍼 번호, 게임 속 위치, 텐트, 채팅, 건배(짠), 그리고 마이크 버튼을 누르는 동안의 음성이 실시간으로 전해져요. 운영자는 이 내용을 저장하지 않아요. 브라우저끼리 직접 연결하는 방식이라 서로의 IP 주소가 상대 브라우저에 보일 수 있어요.

6. 운영자의 이용 제한

운영자는 이용 약속을 어긴 캠퍼의 채팅·음성을 정해진 시간 동안 막거나, 박지에서 내보내거나, 접속을 막을 수 있어요. 이 기록(캠퍼 번호, 그때의 캠퍼 이름, 종류, 끝나는 시각, 운영자 서명)은 함께하기로 다른 이용자의 게임에 전해지고, 서버에도 저장돼요. 제한이 끝나면 30일 안에 지워요.

7. 기기에 저장하는 것

캠퍼 이름·모습·장비, 무작위 캠퍼 번호, 설정, 받은 도장, 레벨·경험치·오늘의 의뢰 진행, 내 것이 된 장비, 야영 일지(1박한 날짜·박지·날씨·장비), 칭호, 마지막으로 간 박지, 기기 열쇠는 이 기기에 저장해요. 진행은 3번처럼 서버에도 저장해요. 브라우저 데이터를 지우면 이 기기의 사본은 함께 지워지지만, 다른 기기나 연결 코드로 다시 이어 할 수 있어요.

설정 → 진행 백업의 '백업 코드'는 이 내용을 글자로 바꾼 것이에요. 코드는 운영자에게 보내지 않고, 이 코드를 가진 사람은 누구나 같은 캠퍼를 불러올 수 있으니 직접 보관해 주세요.

8. iPhone·iPad 앱

App Store의 아윌비백 앱도 이 방침을 따르고, 웹과 다른 점은 아래와 같아요.

  • 익명 이용 통계(2번)를 보내지 않아요.
  • 기기 이어하기(3번)는 웹과 똑같이 써요. 회원가입이나 로그인 없이 써요.
  • 7번의 진행은 앱의 웹 저장소와 앱 설정에 같은 사본을 두어서, 저장 공간이 모자라 iOS가 한쪽을 비워도 이어져요. 앱을 지우면 이 기기의 사본은 함께 지워져요.
  • 마이크는 함께하기에서 마이크 버튼을 누르고 있는 동안에만 써요. 녹음하거나 저장하지 않고, 아이폰 설정 → 아윌비백에서 언제든 끌 수 있어요.
  • 게임 파일이 앱 안에 들어 있어서 사이트 호스팅과 라이브러리 전송(4번)을 거치지 않아요. 글꼴(Google Fonts), 함께하기 신호 서버(PeerJS), 날씨(Open-Meteo)는 웹과 같아요.
  • 다른 회사의 앱·웹사이트에 걸친 추적을 하지 않고, 광고 식별자를 쓰지 않아요.

9. 안전성 확보 조치
